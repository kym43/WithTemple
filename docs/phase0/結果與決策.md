## 證據性質

本結論來自 Agent 對專案文件、公開資料、UX 流程、安全護欄、隱私與工程範圍的案頭審查，不包含真實使用者訪談、行為測試、文化顧問簽核或 7–14 天回訪。

因此本文件能授權核心功能進入開發，但不能用來宣稱：

- 使用者確實需要或願意持續使用本產品。
- 任何完成率、誤解率、留存率或商業轉換率已達標。
- 擲筊名稱、筊象解釋或停止規則獲得宮廟或民俗專業人士認可。
- WishTemple 代表任何實體宮廟或全台統一習俗。

## 案頭查證摘要

| 發現 | 影響 |
|---|---|
| 政府使用者研究指引仍以實際或可能使用服務的人為研究對象 | Agent 不虛構完成率或需求數據；真人研究改為未來產品學習 |
| 公開文化來源對筊杯陰陽面稱法及未允可筊象名稱並不完全一致 | 不由 Agent 選定「全台唯一正確」的正式擲筊規則 |
| LLM 替代真人可能扁平化群體與生活經驗 | AI 模擬只作紅隊與排練，不作正式樣本 |
| A 版不依賴隨機結果，也不要求真實願望或求問 | 可透過保守範圍先行開發 |
| B 版即使加入揭露，仍可能被理解成神明回覆或決策指令 | 限制在內部原型，公開前另行驗證 |

## 風險接受紀錄

團隊接受「先開發、後取得真實市場證據」的產品風險，以縮短等待時間。對應控制措施如下：

- 不把 Agent 推演寫成真實使用者研究結果。
- Phase 2A 成功標準先採工程品質、任務可操作性、隱私與無障礙驗收，不使用虛構百分比。
- Alpha／TestFlight 開始後，再從自願回饋與真實使用情況確認需求、理解度及留存。
- 若未來要公開 B，才重新啟用訪談、原型測試與文化審閱；結果不影響已完成的 A 版核心功能。
