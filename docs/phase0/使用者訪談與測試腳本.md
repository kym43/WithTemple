# Phase 0 使用者訪談與測試腳本

> 狀態：未來選用研究工具。自 2026-09-30 起不再阻擋 Phase 2A；若要公開擲筊或取得真人需求／理解證據，再依本腳本執行。

建議時間：探索訪談 20–25 分鐘；兩版原型 25–35 分鐘；結尾 5 分鐘。

## 主持人開場

> 謝謝你參與。我們正在研究一個私人數位祈願概念，不是在測試你，也沒有正確答案。這是尚未上線的虛構品牌，不代表任何實體宮廟。今天請不要輸入或說出真實願望、健康、財務或其他敏感內容，可以使用我提供的研究情境。你可以跳過任何問題，也可以隨時停止。

分別詢問並記錄：

- 是否同意參與研究。
- 是否同意主持人做文字筆記。
- 若要錄音、錄影或錄製螢幕，逐項另問；不同意時仍可繼續。

## 概念介紹前的探索訪談

依回答追問具體最近一次經驗，不要讀出期待答案。

1. 當你有一件放在心上的事，通常會怎麼整理、記住或尋求支持？
2. 最近一次參拜宮廟或接觸民俗文化是什麼情境？若沒有，原因是什麼？
3. 你是否用過擲筊、求籤或農民曆？分別在什麼情境使用？
4. 如果手機提供私人祈願紀錄，你會在什麼情境想用？什麼情境絕對不會用？
5. 哪些設計會讓這類產品顯得尊重？哪些會讓你覺得消費信仰、不可信或有壓力？
6. 你會擔心它保存哪些資料？什麼資料不應離開裝置？
7. 如果不能或不想在線上參訪，你會希望產品如何協助你前往實體宮廟？

此時才讀概念卡：

> WishTemple 是完全虛構的線上廟宇品牌，提供私人、保存在自己裝置上的數位祈願與文化內容。它不代表實體宮廟、不代辦宗教儀式，也不保證任何祈福或結果。

8. 請用自己的話說明你覺得這個產品是什麼、不是什麼。
9. 這個概念對你有沒有價值？請說一個真的可能使用的時間與情境；若沒有，也請直接說明。
10. 你是否期待祈願後能擲筊？為什麼？你會把結果看成什麼？

## 原型任務

每位參與者都測 A、B 兩版。`P001、P003…` 使用 AB；`P002、P004…` 使用 BA。第二版換另一個研究情境，避免只記住操作。

研究情境一：

> 最近生活節奏有些忙，你想留下一個「希望接下來能更平靜安排生活」的私人願望。不要輸入自己的真實內容。

研究情境二：

> 你想為接下來的一段學習或工作留下「希望能穩定完成計畫」的私人願望。不要輸入自己的真實內容。

對每一版只說：

> 請從首頁開始，用你自然會採取的方式完成這件事。過程中請說出你以為每個畫面會發生什麼。我不會提示操作；若你卡住，可以告訴我。

主持人觀察但不立即追問：

- 是否理解可以略過文化引導。
- 是否選擇文字或心中默念。
- 是否找到保存動作並辨識完成狀態。
- 是否能在「我的」找到紀錄。
- B 版是否主動啟動擲筊、閱讀說明、嘗試重擲，或以筊象重新判定願望是否完成。

## 每版完成後追問

先開放回答，再問選項；不要先重述正確概念。

1. 你剛剛完成了什麼？從哪一刻開始算完成？
2. 這筆內容存在哪裡？誰看得到？
3. 你覺得這個品牌和實體宮廟有什麼關係？
4. 哪個字句或畫面讓你猶豫、不舒服或不相信？
5. 如果在真實情境中，你會使用嗎？何時？
6. 請以 1–5 分評價「尊重文化」與「值得信任」，並解釋分數。

B 版追加：

7. 擲筊前，你的願望是否已完成？為什麼？
8. 你認為畫面上的筊象是什麼性質的結果？它能不能替你做決定？
9. 如果結果不是你期待的，你接下來會怎麼做？
10. 如果這件事涉及身體不適、人身安全、法律期限或金錢損失，這個結果會不會讓你延後尋求專業協助或查證？為什麼？
11. 你是否會想再擲一次？最多幾次才合理？什麼提示會讓你願意停止？
12. 「略過」與「查看說明」是否容易找到？你會不會覺得不擲筊就少完成一件事？

## 兩版比較

1. 哪一版更符合你真正的需求？原因是什麼？
2. B 版讓核心祈願更完整、更混亂，還是沒有差別？
3. 若 B 版完全不上線，A 版是否仍值得使用？
4. 有哪些內容一定要經民俗或宮廟實務顧問確認，你才會信任？

## 7–14 天回訪

不展示擲筊結果，只詢問核心回顧需求：

1. 這段期間是否有一刻想回來看先前的願望？實際有沒有回來？
2. 觸發或阻止回顧的是什麼？
3. 你期待看到原文、日期、自己的反思，還是其他內容？
4. 提醒會有幫助還是形成壓力？什麼頻率或情境不可接受？

## 提前停止條件

若參與者情緒不適、開始揭露不希望保存的敏感內容，或把原型當成緊急／專業建議來源，立即停止任務，提醒這只是研究原型並建議依現實情境尋求合適真人或專業協助。主持人不得替參與者解讀筊象。
