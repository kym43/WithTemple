# 低擬真原型 A：核心祈願

目的：測試不含擲筊時，使用者能否理解並完成「選擇神明 → 文化引導 → 寫下或默念 → 保存 → 查看紀錄」。這是研究用畫面腳本，不是最終 UI 或正式文化文案。

## A0 首頁入口

```text
心願廟

留一個只屬於自己的願望
[開始祈願]

這是虛構的線上廟宇與私人文化體驗，
不代表或代辦任何實體宮廟儀式。
```

觀察：能否找到入口；是否留意品牌揭露；是否誤以為是實體宮廟服務。

## A1 選擇神明

```text
想向哪位神明表達心願？

[神明內容卡 1]
[神明內容卡 2]
[我還不確定，先了解信仰脈絡]

原型中的神明名稱、由來與參拜提醒，
需經內容來源盤點及顧問審閱後才會定稿。
```

測試時卡片使用「神明內容卡」占位，不用未審閱的由來、職掌或「最靈驗」分類。

## A2 靜心與文化引導

```text
先讓自己安靜一下

接下來是一段可略過的文化引導。
你可以閱讀後繼續，也可以直接表達心願。

[閱讀引導]  [略過]
```

觀察：「略過」是否被理解為完整且同等有效的路徑。

## A3 表達心願

```text
用適合你的方式表達

( ) 寫下一段只保存在此裝置的文字
( ) 在心中默念，不輸入內容

研究原型請勿輸入真實願望，請使用提供的情境。

[繼續]
```

若選擇文字，顯示預填的研究句子，不讓參與者自由輸入敏感內容。若選擇默念，保存的紀錄只顯示「以心中默念完成」，不推測內容。

## A4 保存前確認

```text
確認留下這個願望？

• 這是私人數位紀錄，不是實體宮廟代辦
• 正式產品預計只保存在你的裝置
• 你之後可以查看或刪除

[保存願望]
```

研究原型本身不得聲稱真的寫入裝置；主持人需事先說明這是假資料演示。

## A5 完成

```text
願望已保存

你已完成這次私人祈願紀錄。

[查看我的願望]  [回到首頁]
```

主要驗證點：受測者能否明確指出此畫面代表流程已完成。

## A6 我的願望

```text
我的願望

[今天] 希望能平靜安排接下來的生活
僅保存在此裝置

[查看]  [刪除]
```

觀察：能否找到紀錄、理解隱私範圍及刪除能力。原型不真的保存或刪除資料。

## 點擊規則

- `開始祈願 → 選擇任一卡片 → 閱讀或略過 → 選擇表達方式 → 繼續 → 保存願望 → 完成`。
- 兩種表達方式都必須能完成，不以輸入文字作為必要條件。
- A1–A4 都提供文字標示的「返回」與「離開祈願」。返回保留先前選擇；若已有研究用文字，離開時顯示「放棄這次尚未保存的內容？」並提供「繼續祈願／放棄並離開」。
- A5 之後已完成保存；返回或離開都不得把狀態改回未完成。
- A6 的刪除先顯示「刪除後無法從 App 復原」以及「取消／刪除願望」。這一輪不把刪除列為完成主任務，只觀察參與者是否理解控制權。
- A 版不出現擲筊入口、結果或相關文案，作為核心基線。
- 原型控制項不只用圖示或顏色傳意。主持人可依參與者需求放大或朗讀畫面，但需在計分表記錄協助類型。
