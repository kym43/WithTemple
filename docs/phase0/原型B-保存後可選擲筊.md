# 低擬真原型 B：願望保存後可選擲筊

> 狀態：僅限內部原型／feature flag，不屬於公開 MVP。不得接正式導覽、持久化、付費或商店素材；若日後決定公開，再啟動真人測試與文化顧問審閱。

目的：在不改變核心祈願完成點的前提下，供內部走查可選擲筊的流程、安全與反權威護欄。這不是正式儀式規則、最終 UI 文案或公開功能規格。

## B0–B5 核心流程

完全沿用[原型 A](原型A-核心祈願.md)的 A0–A5。B5 必須先完整顯示：

```text
願望已保存

你已完成這次私人祈願紀錄。
```

不可把「擲筊」按鈕放在保存按鈕之前，也不可用未完成進度、警示色或倒數催促。

## B6 可選擲筊

```text
接下來要體驗擲筊文化嗎？（可略過）

這是數位模擬的民俗文化體驗，不代表神明真實回覆，
不預測未來，也不替你做醫療、法律、財務或安全決定。
無論是否體驗、得到何種筊象，你的願望都已保存。

[體驗擲筊]  [略過，查看願望]
[這是什麼？]
```

「體驗擲筊」與「略過，查看願望」使用相同視覺權重與觸控尺寸，不用主色／灰色製造必要與次要的暗示。觀察：是否主動開始、閱讀說明或略過；是否把擲筊視為尚未完成的必要步驟。

## B7 提問引導

```text
先在心中想一件能用「是／否」回應的事

不用輸入，也不會保存你的問題。
請避開需要專業協助或立即行動的醫療、法律、財務與安全事項。

[我準備好了]  [結束體驗]
```

研究時使用主持人提供的中性情境，不請參與者透露真實問題。

## B8 數位擲筊

```text
數位擲筊文化體驗

[兩枚筊的占位圖]

[擲筊一次]  [結束體驗]
```

研究結果由主持人依測試編號預先指定，不能因受測者背景、願望或付款改變：P001/P004/P007/P010 顯示聖筊；P002/P005/P008 顯示笑筊；P003/P006/P009 顯示陰筊。

## B9 結果草案

以下文案只用於顧問與使用者檢驗，不宣稱為全台唯一解釋。

### 聖筊

```text
聖筊

在本原型採用的常見說法中，這組筊象通常被理解為較明確的允可。
這是數位文化體驗，不是神明真實回覆，也不替你做決定。
你的願望在擲筊前已保存。

[完成並查看願望]
```

### 笑筊

```text
笑筊

在本原型採用的常見說法中，這組筊象表示沒有明確的回答。
你可以重新整理問題後再體驗一次，或先停在這裡。
這是數位文化體驗；你的願望早已保存。

[重新說明一次]  [停止並查看願望]
```

若選擇「重新說明一次」，不要求輸入內容，只回到 B7；下一次結果後只提供「停止並查看願望」，不再提供重擲。

### 陰筊

```text
陰筊

在本原型採用的常見說法中，這組筊象不是明確的允可。
先停下來想一想，也可以改天再問；不要用這個結果延後必要的專業協助。
這是數位文化體驗；你的願望早已保存。

[停止並查看願望]
```

## B10 回到紀錄

畫面與 A6 相同。研究版不預設保存筊象，不在願望卡上標示成功／失敗，也不出現支持、改運、再試一次或分享結果的入口。

## 強制停止規則

- 聖筊與陰筊：本次沒有重擲入口。
- 笑筊：本研究草案最多一次重新說明；若參與者選擇重試，第二次固定展示陰筊草案，且結果頁只有「停止並查看願望」。
- 使用返回再進入也視為同一次研究工作階段，主持人記錄額外重擲嘗試，不提供新結果。
- 受測者若表示結果會改變必要醫療、安全、法律或財務行動，立即終止測試並記錄安全紅旗。
- 正式停止規則必須由顧問審閱與使用者測試共同決定，不能只因原型操作順暢就定案。
- 三種結果卡維持相同排版、字級與中性色彩，不使用紅／綠吉凶暗示、慶祝動畫、音效、震動或分享按鈕；筊圖旁一定顯示文字名稱。
